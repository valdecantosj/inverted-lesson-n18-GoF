Fachada (Facade)

¿Cómo ofrecer una interfaz unificada a un subsistema?

Contexto / Problema

Se requiere una común, unificada para un conjunto de implementaciones o interfaces dispares —como en un —. Si el cliente depende de muchos componentes internos, queda fuertemente acoplado a los detalles y los cambios internos pueden afectarlo.

Solución

Defina un único punto de conexión con el subsistema: un objeto fachada que lo envuelve:

  • Presenta una única interfaz unificada y coordina las operaciones entre los componentes del subsistema.
  • Funciona como un front-end simplificado sin alterar las interfaces internas.
  • Brinda : el depende de la Fachada y no de las clases internas.

Ejemplo

  • NuevaEra (Larman): Reglas de negocio conectables. La Venta llama a FachadaMotorReglasPDV.getInstancia().esInvalido(ldv, this) sin conocer cómo se evalúan internamente las reglas.
  • En la clase (Pedidos): PedidoFacade.procesarPedido(pedido) coordina inventario, pago, transporte y notificaciones sin que el cliente conozca la maquinaria interna.

Representación en UML

  • Client: solo se relaciona con la Facade, el punto de acceso al subsistema.
  • Facade: coordina varias operaciones del subsistema para completar una solicitud.
  • Clases del subsistema: contienen la funcionalidad real y permanecen ocultas (dependencias discontinuas).

Discusión

  • Ocultamiento: Reduce las dependencias directas del cliente con los componentes internos y facilita cambios internos sin afectar al cliente (separación de intereses).
  • Costo: Introduce una adicional. Si la Fachada concentra demasiadas responsabilidades, corre el riesgo de volverse excesivamente compleja.

Patrones relacionados

  • Singleton: normalmente se accede a las fachadas mediante Singleton cuando se requiere un punto compartido.
  • Adapter vs. Facade: Fachada proporciona una interfaz simplificada para un subsistema; Adapter adapta interfaces incompatibles existentes.
  • Composite: Fachada simplifica el acceso; Composite permite tratar de forma uniforme objetos individuales y compuestos.
