Patrones de Diseño GoF

Guía de consulta interactiva para la Clase 18

1. Adaptador (Adapter)

Estructural

Convierte la interfaz de un componente externo para hacerla compatible con la que espera la aplicación.

GRASP: Indirección • Variaciones Protegidas

2. Factoría (Factory)

Creacional

Aísla y concentra la responsabilidad de instanciación con consideraciones o parametrizaciones complejas.

GRASP: Fabricación Pura • Alta Cohesión

3. Singleton

Creacional

Garantiza una única instancia de una clase y provee un punto de acceso global y controlado.

Control de Instancia • Acceso Global

4. Fachada (Facade)

Estructural

Ofrece una interfaz unificada y de alto nivel que simplifica el uso de un subsistema complejo.

Punto de Entrada • Bajo Acoplamiento

5. Estrategia (Strategy)

Comportamiento

Encapsula familias de algoritmos y políticas variables haciéndolas intercambiables en tiempo de ejecución.

GRASP: Polimorfismo • Abierto/Cerrado
